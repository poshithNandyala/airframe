How to make a window click-through on Windows

A floating video should not block the app underneath it. This is how click-through works on Windows, how to use it in Airframe, and what to do when a window refuses to cooperate.

By Poshith Nandyala Updated November 25, 2026 4 min read
Short answer

Bring the app you want to use to the front, then press Alt+L in Airframe. The video becomes click-through: clicks, scrolling, dragging and hover go to the window behind it. Press Alt+L again to take the video window back.

A floating video is only useful if it does not become a wall between you and your work. Click-through fixes that: the video stays visible, but your mouse acts on the window underneath it. Windows can do this, but there is no checkbox for it. It is a window-style trick, and the implementation details matter.

What click-through actually means

Normally, the topmost window under your pointer receives the click. Click-through tells Windows to skip that window for hit-testing, so the click goes to the next eligible window below. Scrolling, dragging and hover can follow the same path.

It is separate from transparency. A window can be fully opaque and click-through, or fully transparent and still capture clicks. Airframe exposes both controls independently because they solve different problems.

How Airframe does it

Airframe's display mode is toggled with AltL. The flow is deliberately simple:

  1. Bring the app you want to use to the front. Airframe targets the top window behind it, so the order matters.
  2. Press AltL. A toast names the target window.
  3. Work through the video. Clicks, wheel, drag and hover reach the target. The video keeps playing.
  4. Press AltL again. The video window takes mouse input back.

Under the hood, Airframe uses Electron's setIgnoreMouseEvents and re-asserts the state after display changes or taskbar interaction. It also disables Chromium's DirectComposition path for its top-level window. That detail matters for WinUI 3 and WebView2 apps: a Chromium window created with WS_EX_NOREDIRECTIONBITMAP can refuse to route pointer input through, even when the transparent style is set. The classic redirection surface makes click-through work with those apps.

How Windows click-through works for developers

At the Win32 level, the usual combination is two extended window styles:

  • WS_EX_TRANSPARENT (0x00000020) makes the window transparent to hit-testing.
  • WS_EX_LAYERED (0x00080000) is often required for the effect to behave consistently, especially with per-pixel alpha.

An AutoHotkey toggle for the active window looks like this:

; AutoHotkey v1 - toggle WS_EX_TRANSPARENT on the active window
F8::
  WinGet, activeId, ID, A
  WinSet, ExStyle, ^0x20, ahk_id %activeId%
return

The ^ XORs the style, so the same hotkey turns it back off. Keep that undo path in mind: once a window is click-through, you may not be able to click its own close button. A global hotkey still works.

In Electron, the equivalent is:

win.setIgnoreMouseEvents(true, { forward: true });

The forward option forwards mouse move messages so hover effects can still work. It does not forward clicks; those go to the window below.

Set up click-through in Airframe

  1. Open YouTube in Airframe and start the video.
  2. Open the app you want to work in and click its title bar so it is the front window.
  3. Press AltL. The toast should name that app.
  4. Click, scroll and drag through the video. If the target is correct, the app responds.
  5. Press AltL to reclaim the video, or use the global shortcuts to control playback.

At 0% opacity, the window is invisible and click-through automatically. AltShift↑ brings it back. That combination is useful for audio-only playback or a video you only want to hear.

When click-through does not work

  • The target app is elevated. A normal-privilege app generally cannot send input to an administrator window. Run both at the same level if you control them.
  • A UAC prompt is open. The secure desktop is above everything and is not a normal click-through target.
  • The game is exclusive fullscreen. Use borderless windowed mode.
  • Another topmost window is above the target. Close or unpin it, then bring the target forward again.
  • The target is minimized. Restore it before toggling.
  • The app uses raw input. Some games and drawing apps read the device directly and ignore synthesized or forwarded pointer messages.
  • A shortcut conflict. Another app may be capturing AltL. Close it or use CtrlAltL, which Airframe also accepts.

What click-through is good for

  • Tutorials over an editor. Follow along in Photoshop, Premiere or VS Code without moving the video.
  • Reference video over a document. Keep a talk or demo visible while you take notes.
  • Music video as a desktop element. Fade it, click through it, and forget it is a window.
  • Borderless games. Keep a guide or stream visible while the game receives your input.
  • Presenting. Keep a clip visible while you drive the app behind it.

The bottom line

Click-through is the feature that turns a floating video from an obstacle into part of the desktop. Airframe gives it a global shortcut and handles the Chromium/WinUI edge cases that make naive implementations fail. Bring the target forward, press AltL, and work through the video.

Frequently asked questions

What does Alt+L do in Airframe?

It toggles click-through. When it is on, pointer input goes to the top window behind Airframe. When it is off, the video window receives clicks again. A toast confirms the change.

Can I still control the video while click-through is on?

Not with the mouse. Use the global shortcuts for play, opacity, hide and show, or press Alt+L to turn click-through off and use the YouTube controls.

Is click-through the same as transparency?

No. Opacity changes how visible the window is. Click-through changes where mouse input goes. Airframe lets you use either one independently, and at 0% opacity the window is both invisible and click-through.

Does click-through work with games?

It works best with games in borderless windowed mode. Some games use raw input or exclusive fullscreen and may not receive the forwarded pointer input. Test with the specific game.

Why does the click-through target the wrong window?

Airframe targets the top window behind it. Bring the app you want to use to the front before pressing Alt+L. If an elevated app or UAC prompt is involved, Windows may block input from reaching it.

Is there a built-in Windows setting for click-through?

No. Windows exposes it to developers through extended window styles. End users normally need an app such as Airframe, a window utility, or a script.
