How to watch YouTube while gaming on Windows

One monitor is enough if the game runs borderless and the video knows how to stay out of the way. Here is the setup, the performance cost, and how to keep it off your stream.

By Poshith Nandyala Updated November 25, 2026 4 min read
Short answer

Set the game to borderless windowed mode, open YouTube in Airframe, and park the video in a corner. Exclusive fullscreen can cover any always-on-top window. A second monitor is still the best option for performance.

Watching a guide, a stream or a video essay while you game is a normal second-screen habit. On a single monitor it takes a little more setup, because the game and the video are competing for the same display. The key is borderless windowed mode and a video window that knows how to stay out of the way.

Borderless windowed vs exclusive fullscreen

Exclusive fullscreen gives the game direct control of the display. That is good for latency and some HDR setups, but it also means the game can cover every normal window, including an always-on-top video. Borderless windowed mode keeps the game inside the Windows desktop compositor, where overlays can appear.

Most modern games call this "Borderless," "Fullscreen Windowed" or "Windowed Fullscreen." The exact label varies, but the behavior is the same: the game fills the screen without taking exclusive control. If the video disappears when you alt-tab back into the game, this setting is the first thing to change.

Set up Airframe over a game

  1. Switch the game to borderless windowed mode. Apply the setting and restart the game if it asks.
  2. Launch Airframe and open YouTube. Start the video or playlist before you go back to the game.
  3. Resize and park the window. A corner works best. Avoid the area where the game shows its minimap, kill feed or ability bar.
  4. Set opacity. AltShift↓ fades the video. 60–80% is a reasonable starting point for a game.
  5. Bring the game to the front and press AltL. Your mouse now controls the game through the video.
  6. Use AltH to hide the video instantly. Useful for a cutscene, a boss fight or a ranked match.

Airframe has no taskbar button, so you will not find it in Alt+Tab. Use its global shortcuts — AltH to show it again, AltB to return to the launcher, and AltQ to quit.

Performance tips

  • Match the video to the job. 720p is enough for a small corner window. 1080p is fine on most discrete GPUs; 4K is usually wasted on a 400-pixel-wide box.
  • Pause when you are not watching. A paused video still holds a window, but it stops decoding.
  • Close other browser tabs and players. Two YouTube windows are two decoders.
  • Use hardware acceleration. Chromium hardware-decodes common YouTube codecs by default. If you have disabled it globally, expect more CPU use.
  • Watch the frame-time graph, not just average FPS. A video can cost a few frames without changing the average much, but cause uneven pacing.
  • Try exclusive fullscreen for competitive games. If you do not need the video during a match, hide Airframe and switch modes.

Keep the video out of your stream

If you stream or record, the last thing you want is a random YouTube recommendation in the corner of the VOD. Airframe's shield is on by default. In OBS, use Display Capture for the desktop; the protected window is excluded. Game Capture only captures the game, so the overlay is not included either.

If you want viewers to see the video, turn the shield off with AltS and capture the window or display normally. If you are streaming copyrighted music or video, check the platform's rules and the rights holder's policy. That is a separate problem from the capture setup.

Anti-cheat and fair play

Airframe is an Electron window that sits above the game. It does not inject code into the game process, hook DirectX, or modify game memory. That makes it different from a traditional game overlay, but it does not guarantee that every anti-cheat or tournament ruleset allows it.

For competitive play, check the game's rules. For casual play, a video in the corner is usually fine. Do not use any overlay to gain information the game does not give you; that is a cheating problem, not a video-player problem.

The bottom line

On a single monitor, borderless windowed mode plus a small floating YouTube window is the practical setup. Airframe keeps the video on top, lets you fade it, lets your mouse pass through to the game, and keeps it out of most captures. Start at 720p, park it in a corner, and hide it when the game needs your full attention.

Frequently asked questions

Does watching YouTube lower FPS?

It can. Video decode and Chromium composition use some CPU and GPU. A small 720p or 1080p window is usually light on a modern system; 4K, high frame rates and multiple players cost more. Measure with your game overlay and lower the video resolution if you notice stutter.

Does Airframe work over fullscreen games?

It works best in borderless windowed mode. Exclusive fullscreen can cover every always-on-top window because the game takes direct control of the display. Switch the game to borderless or windowed mode if the video disappears.

Can I use Airframe on a single monitor?

Yes. That is the main use case. Resize the video to a corner, set opacity, and use click-through so your mouse controls the game.

Will an overlay get me banned by anti-cheat?

Airframe is a separate window. It does not inject into the game or hook its process. Always-on-top overlays are generally allowed, but anti-cheat policies vary. Check the game and publisher rules if you are unsure.

Can I hide the video from my stream?

Yes, in most cases. Leave the screen-share shield on and use OBS Display Capture. The window is excluded from the capture. Turn the shield off if you want viewers to see it.

Does Airframe work with HDR or variable refresh rate?

HDR and VRR behavior depends on the game, the display mode and the GPU driver. Borderless windowed mode can change how both are handled. Test the game with the overlay before committing to a ranked match.
