Always-on-top YouTube player for Windows

Windows will happily let YouTube disappear behind your editor. Here is how to keep it above everything else, which tools actually do it, and where each one stops.

By Poshith Nandyala Updated November 25, 2026 5 min read
Short answer

Airframe is a free Windows app that keeps YouTube in a borderless, always-on-top window. Install it, pick YouTube, and the video stays above your work. Press Alt+T to toggle pinning and Alt+L to make the window click-through.

Windows has no built-in switch that says "keep this YouTube video on top of everything." The usual workarounds are picture-in-picture in a browser or PowerToys Always on Top. Both work, but they leave you with a tiny video or a browser window with its title bar, tabs and address bar attached.

Airframe is a small Windows app built for the other job: a full YouTube window that behaves like part of your desktop. It is borderless, stays above normal windows, and adds the controls a pinned browser tab cannot offer — opacity, click-through, a screen-share shield and global shortcuts.

What "always on top" actually means

Windows stacks windows in a z-order. The active window is normally at the top, and clicking another window moves that one above. A window with the topmost flag stays above normal windows even when it is not focused. That is the flag Airframe sets by default.

Two details matter in practice:

  • Topmost is not exclusive. Another topmost window can still sit above Airframe. So can UAC prompts and some system dialogs.
  • Exclusive fullscreen bypasses the normal desktop compositor. A game in true fullscreen can cover every always-on-top window. Borderless windowed mode is the reliable setup.

Airframe also removes the title bar, taskbar button and tray icon, so the window reads as a screen rather than another app. You move it by dragging the thin strip at the top or any edge, and you resize it from any edge.

If you only need a video visible for five minutes, browser picture-in-picture is fine. If you want a YouTube window that lives on your desktop all day, a dedicated player is less friction and far more controllable.

Why a dedicated window beats pinning a browser tab

A pinned browser still behaves like a browser. The tab bar, address bar and window controls take space, the page can be reloaded by accident, and the window is tied to the rest of your browsing session. Airframe strips all of that away and keeps the YouTube session in its own profile.

The practical differences:

  • No title bar or taskbar button. The video does not clutter Alt+Tab or your taskbar. The launcher is the only visible entry point.
  • Opacity from 0 to 100%. Fade the video to a hint over an editor, or bring it back with AltShift↑. The default is 93%, which keeps the video readable without feeling like a second monitor.
  • True click-through. AltL sends clicks, scrolling, dragging and hover to the app behind the video. You keep watching while you work in the window underneath.
  • Screen-share shield. The window is excluded from most Windows capture paths, including Teams, Zoom, Meet and OBS. It is on by default.
  • Global shortcuts. Every control works while another app has focus, so you do not have to hunt for the video window.
  • Touchpad and mouse gestures. Two-finger swipe goes back and forward, and mouse side buttons work like a browser.

How to set up Airframe in three steps

  1. Download the installer. The Windows installer is about 121 MB. A portable ZIP is available if you prefer not to install. Both come from the v1.5.0 GitHub release.
  2. Run it. No admin rights are required. SmartScreen may warn because the installer is not code-signed yet; choose More info and then Run anyway if you are comfortable with the source.
  3. Pick YouTube. The launcher opens the YouTube screen. Sign in if you want your subscriptions and playlists. The window stays on top by default.

From there, resize the window to the corner you want and set opacity with AltShift↑ or AltShift↓. If you need your mouse back, press AltL after bringing the app you want to use to the front.

If YouTube will not stay on top

Start with AltT. It is easy to unpin the window by accident, and the launcher shows the current state. If pinning is on and the video still disappears, check these in order:

  • The other app is exclusive fullscreen. Switch the game or video app to borderless windowed mode.
  • Another topmost window is above it. Task Manager, some launchers and a few utilities also use topmost. Close or unpin them.
  • The window is on another monitor. Press AltShiftD to move it to the next display or recenter it.
  • The app is hidden. Press AltH, then check opacity with AltShift↑.
  • UAC or a secure desktop is showing. Windows intentionally puts those above normal windows. Nothing in user mode can cover them.

The bottom line

Browser picture-in-picture is the fastest way to float one video. PowerToys is the right tool if you want to pin any window. Airframe is the option to pick when YouTube itself should live on your desktop: a full window, any opacity, click-through when you need it, and a shield for screen shares.

Frequently asked questions

Is there a built-in always-on-top YouTube player in Windows?

No. Windows can pin a whole window with PowerToys Always on Top, and browsers can float a video with picture-in-picture. Neither gives you a dedicated, borderless YouTube window with opacity, click-through and a screen-share shield. Airframe fills that gap.

Does Airframe work over fullscreen games?

It works best when the game runs in borderless windowed mode. Exclusive fullscreen can cover any always-on-top window because the game takes direct control of the display. If the video disappears, switch the game to borderless or windowed mode.

Is Airframe free?

Yes. Airframe is free and open source under the MIT license. You can download the installer or the portable ZIP from GitHub Releases.

Does it work with YouTube Premium?

Yes. Sign in as usual and Premium videos play. Rented movies and DRM-only content may not play because Electron does not ship Google Widevine.

Can I use Airframe on macOS or Linux?

No. Airframe is built for Windows 10 and Windows 11, 64-bit only.

Why does the video sometimes sit under another window?

Always-on-top is a request, not an absolute rule. Another topmost window, an exclusive-fullscreen game, or a system prompt such as UAC can appear above Airframe. Press Alt+T to re-assert pinning, or close the other topmost window.
